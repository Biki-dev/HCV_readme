# QuantumIQ

**QuantumIQ** is an interactive quiz web app based on HC Verma's Concepts of Physics. It helps students revise and test their understanding of physics through chapter-wise multiple-choice questions with detailed solutions.

[![Deploy with Vercel](https://vercel.app)](https://vercel.app)  

---

## Features

- Chapter-wise MCQ quizzes from **HC Verma (Vol 1+2)**  
- Animated score summary with accuracy display  
- Clean and modern UI with responsive design  
- Retry quiz and track performance instantly  
- 100% client-side – No login/signup required

## Tech Stack

### Frontend
- **React.js** (Vite)
- **Framer Motion** for animations
- **React Circular Progressbar**
- **CountUp.js**
- **Custom CSS**

## Backend
> *This application uses MongoDB and Next.js for the backend.*  
Data is stored in MongoDB and dynamically rendered using Next.js for efficient handling and rendering of content. The backend API is built using Next.js API routes, ensuring smooth interaction between the frontend and the database.
